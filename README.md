# Central de Atendimento TIC

Aplicação interna para técnicos (Python puro).

## Rodar local
```bash
python central_tic_v4_corrigido.py
```
Abre em http://localhost:8895

## Publicar no Render (grátis)
Siga o arquivo **README_DEPLOY.md**.

### Estrutura
```
central_tic_v4_corrigido.py
requirements.txt
render.yaml
templates/
static/
dados/
logs/
backup/
```

### Segurança
Troque senhas padrão após o primeiro acesso.
Não compartilhe a URL publicamente se houver dados operacionais.
